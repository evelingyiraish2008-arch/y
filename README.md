# Mi Mundo 📚

Tu universo, organizado: libros, series, películas, anime, manhwas, personas, parejas BL, colecciones y notas en una sola página.

Abre `index.html` en el navegador. No necesita instalación ni servidor. Los datos se guardan en el `localStorage` del navegador (clave `mi_mundo_data_v16`), así que tus datos anteriores se conservan.

Consejo: en **Personalizar → Copias de seguridad** puedes exportar o importar tus datos en JSON.
